Playback es un marketplace full-stack de segunda mano especializado en videojuegos, consolas y accesorios retro. Pagos reales con Stripe, transferencias automáticas a vendedores, sistema de incidencias, emails transaccionales y asistente de búsqueda con IA.

Proyecto final de bootcamp · **[4Geeks Academy](https://4geeks.com/es)** · Full Stack Developer · cohorte 2025–2026

## 🚀 Inicio rápido (Codespace)

```bash
# 1. Dependencias
pipenv install && npm install

# 2. Edita el archivo .env con tus credenciales

# 3. Base de datos
pipenv run upgrade
pipenv run seed_categories
pipenv run seed_data

# 4. Arrancar
pipenv run start    # backend → :3001
npm run start       # frontend → :3000
```

📖 Guía completa → [Instalación y arranque](./docs/README_SETUP.md)
